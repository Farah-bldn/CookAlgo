# Projet CookAlgo - README

**Étudiants :** Farah BELAIDOUNI & Mehdi RABEHI

## Prérequis
* Node.js et MongoDB doivent être installés.

## Installation
1. Dans le dossier backend :
   npm install

2. Dans le dossier client :
   npm install

## Démarrage du projet
1. Lancer le backend (dossier backend) :
   node server.js

2. Lancer le frontend (dossier client) :
   npm start

## Fonctionnalités
* Recherche avancée, gestion des profils publics/privés, likes et commentaires dynamiques, interface Admin.
